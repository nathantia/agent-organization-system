# Concept Generation

## Process

1. Restate the strategic proposition.
2. Define the human tension.
3. Establish creative criteria.
4. Generate multiple genuinely distinct territories.
5. Avoid execution-first ideas without a durable concept.
6. Test each territory for ownership, emotion, and extensibility.
7. Advance only the strongest territories.

## Output per territory

- name
- core idea
- human truth
- strategic connection
- expression
- channel potential
- risks
